OSM · TPF2 Studio

Pick a place on OpenStreetMap and prepare data for your game.

    Selected extent · © OpenStreetMap contributors
    Shift-click to drop the box center. Use the layer control for OSM or satellite.

    Map square

    Search a place or Shift-click the map. The yellow line is that many metres on the ground, 1:1, for any OSM area.

    Download OSM

    Pulls highways, railways, landuse, water, places, signals, and mapped houses/shops/industry for the yellow box. Garages, sheds and untyped building=yes are skipped.

    Identical OSM queries are cached locally for 6 hours. Public services are requested with attribution and paced requests; HTTP 429/Retry-After is respected. Country extracts (.osm / .osm.bz2) are cropped to the yellow box before convert. PBF needs osmium or a Geofabrik .osm.bz2.

    Workshop mods

    Subscribe via Steam only. Generic street/track/airport packs are listed for any map. Country packs are suggested only when the box is in that country. Missing packs fall back to vanilla TPF2 types.

    Heightmap

    16-bit grayscale PNG cropped to the selected map square. Terrain data uses Terrarium with FABDEM (or Copernicus / SRTM) bare-earth where available.

    Heightmap size is selected from the map preset. Output is capped at 6,145 pixels per side: larger grids scale quadratically and a 16,385-pixel grid can exceed 8 GiB of peak temporary arrays. This cap includes the largest current TPF2 preset.

    Satellite overlay

    Esri World Imagery mosaic covering the selected map square. Attribution is saved alongside exported images.

    Attribution: Esri, Maxar, Earthstar Geographics. Personal overlay use.

    Install & launch

    Finds the TPF2 game, mods, Workshop, and heightmap folders from Steam, then copies the in-game tool into mods/osm_importer_1. Pause the game and open the OSM button on the menu bar.
